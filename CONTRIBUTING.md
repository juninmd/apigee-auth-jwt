# Contributing to juninmd/apigee-auth-jwt

## Introduction
This repository contains the CI/CD pipeline for the juninmd/apigee-auth-jwt project.

## Getting Started
To get started with contributing to this repository, please follow these steps:
1. Fork the repository
2. Clone the repository to your local machine
3. Make your changes
4. Commit your changes
5. Push your changes to your fork
6. Create a pull request

## Commit Message Guidelines
Please follow the standard GitHub commit message guidelines.

## Code Review
All pull requests will be reviewed by the maintainers of this repository.
